# Robot Control GUI
This program is designed to control a Kinova JACO robotic arm with a GUI interface. It allows the user to see a live feed provided by a webcam affixed to the robotic arm, allowing remote operation and helping users to work around visual obstructions. The GUI controls both the rotation and translation of the end effector and is designed to be extensible if needed.

## Main Features:
- **Switchable webcam feeds:** The robot can switch between multiple different webcam feeds, allowing the user to toggle between them.
- **Full arm control:** Users can control both the rotation and translation of the robotic arm's end effector, giving the user fine-grained control over the whole system.
- **Simple interface:** The interface is simple to understand, and the number of buttons used is minimised to make the system usable on a small screen. However, more work is needed on aesthetics.
